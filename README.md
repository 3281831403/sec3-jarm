授权响应改成签名格式之后，客户端只解了载荷就直接采信，签名根本没验：现在要求任何授权响应都必须带签名，签名要覆盖整个载荷，签发者必须是受权方，受众必须是本客户端，响应还必须绑定本次请求的随机值。明文响应不能代替签名响应，批量校验时每条响应各自独立判断。任何未验签的响应一律拒绝，随机值不符的响应一律拒绝。

契约

授权响应必须采用签名格式，签名覆盖头部与载荷的完整内容。
签发者必须与受权方完全一致。
受众必须包含本客户端。
响应必须携带并匹配本次请求的随机值。
不允许用明文响应替代签名响应。
批量校验时每条响应独立验签、独立判定。

不变量

未经验签的响应一律拒绝。
随机值不匹配的响应一律拒绝。
